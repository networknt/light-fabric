# Historical A1 qualification artifacts

These files record the former Workflow credential-broker implementation and its
local qualification. The broker's browser callback and backend enrollment routes
were retired. The `local-activation-receipt.json` file is the original captured
observation, including its former callback URI and TLS check; it is not current
deployment configuration. See [Workflow Invoke](../../../product/light-workflow/workflow-invoke.md)
for the current Gateway-to-Workflow user-token contract and asynchronous LONG
registration.
